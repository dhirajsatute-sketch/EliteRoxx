# Flashy Hero Animations

A premium animated hero section created using HTML, CSS, and JavaScript. This project showcases interactive particle systems, glowing aurora effects, animated statistics, and modern UI design suitable for agency websites, portfolios, and SaaS landing pages.

## Features

- ✨ HTML5 Canvas animations
- 🌌 Interactive particle network
- 🎨 Aurora glow effects
- 💫 Mouse interaction & spark effects
- 📈 Animated statistics counters
- 📱 Fully responsive design
- ⚡ Pure JavaScript (No libraries)
- 🎯 Modern CTA buttons and typography

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Canvas API

## Perfect For

- Landing Pages
- Agency Websites
- Portfolio Websites
- SaaS Products
- Startup Websites
